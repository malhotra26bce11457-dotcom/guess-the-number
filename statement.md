# Guess the Number - Project Statement
## 1. Problem Statement
Guess the number is a interesting python- based game in which the computer generates a random number between 1 and 100.
The player has to guess the number within a maximum of 10 attempts. 
After each guess made by the player, the program gives a message to help the player.
if the guess is lower than the random number, it displays that the guess it  low. 
if the guess is higher than the random number, it displays that the guess is high.
if the guess is correct, the game displays a woohoo! message and the number of attempts used. 
The main purpose of this project is to create a simple interaction game while using basic python programming concepts. 
## 2. Scope of the project 
The project is designed as a simple command- line guessing game. It can be used to understand and python programming concepts such as:
- Varibles
- User input
- Random number generation
- while loop
- if, elif and else statements
- Break statement
- Counters and attempts
The project can be improved is the future by adding different difficulty levels, score calculations, replay options and a graphical user interface.
## 3. Target users. 
The target users of this project are.
Beginners who are learning python programming.
Students who want to practice basic programming concepts. 
user who wants to play a simple number guessing game. 
anyone interested in small command- line based games.
## 4. High - Level Features
The main features of the project are:
Generates a random number between 1 and 100.
Allow the user to enter a guess.
Display a woohoo! message when the correct number is guessed.
Display the number of attempts used by the player.
Ends the game when the correct number is guessed or all attempts are used.
