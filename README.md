# Guess the Number Game
## 1. Project Overview 
Guess the Number is the interesing python game in which the coumpter randomly guesses the number between 1 and 100.
The player has to guess the correct number within a maximun of 10 attempts. 
After every guess made by the player the program provides a hint to the player by displaying whether the guessed number is bigger or smaller. 
If the player guesses the correct number, the game display a woohoo! message and the number of attempts made by the player while playing the game. 
If the player cannot guess the number within 10 attempts, the game ends and display the correct number which coumpter randomly guess.
## 2. Project Features
The important features of guess the number game are as follow:
1. Generate a random number between 1 and 100.
2. Allow the player to enter their number.
3. Provide hints to the player whether the number which they have guess is smaller or bigger number than the correct number.
4. Allow maximum 10 attempts to guess the number.
5. Count the number of attempts made by the player in the game.
6. Display a woohoo! message when the correct number is guessed by the player.
7. Display the correct number when all the 10 attempts are used.
8. Use conditional statements such as 'if', 'elif' and 'else'.
9. Use a 'while' loop to control the number of attempts.
10. Use the python 'random' module for random number generation.
